## pyfcd

Python code to perform free surface profilometry with synthetic schlieren imaging (fast checkerboard demodulation). Code adapted from: https://github.com/kaspervn/pyfcd.

## pypiv

Python code to perform PIV analysis. Mostly wraps around openpiv functions.

## pydata

Functions for image processing and video processing. Most of the code was inherited from: https://github.com/trapped-modes-ltg/fcd-analysis

## aux

Miscelaneous functions to create gifs, average images, etc.
