## pyfcd

Python code to perform free surface profilometry with synthetic schlieren imaging (fast checkerboard demodulation). Most of the code was adapted from: https://github.com/kaspervn/pyfcd.

## pydata

Functions for image processing and video processing. Most of the code was inherited from: https://github.com/trapped-modes-ltg/fcd-analysis

## Aux

Miscelaneous functions to create gifs, average images, etc.
